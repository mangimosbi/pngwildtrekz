# PeakPath – Mountain Climbing Website

Simple 3-page static website about mountain climbing.

## Pages
- **Home** (`index.html`) – Welcome and intro
- **Climbs** (`climbs.html`) – Popular mountain routes
- **Tips** (`tips.html`) – Safety and preparation advice

## Structure
```
mountain-climbing-site/
├── index.html
├── climbs.html
├── tips.html
├── css/
│   └── style.css
├── images/          (empty – add your own photos)
└── README.md
```

## How to use
1. Unzip the folder
2. Open `index.html` in a browser to preview
3. Upload the whole folder to a GitHub repository
4. Enable GitHub Pages (Settings → Pages → Deploy from branch)

No build step needed – pure HTML & CSS.
